Key patterns observed

  • ✦ Both use a role-based onboarding (learner / teacher / parent)
  • ✦ Duolingo is streak-first — gamification lives at every level
  • ✦ Khan Academy separates classroom tools from learner tools
  • ✦ Both gate social / community behind authenticated profile
  • ✦ Duolingo's Shop creates a monetization layer; KA is ad-free
  • ✦ Practice is a top-level section in both, not buried in Learn
